ขั้นตอนที่ 01

หน้าขายของหน้าร้าน (ยิงบาร์โค้ด > เช็คลูกค้า > คิดเงินจบการขาย)

เมื่อลูกค้ามาซื้อเครื่องที่ร้าน: 1. สแกนเลข IMEI บนกล่องเช็คของ → 2. หาเบอร์โทรลูกค้าเก่า/ใหม่ → 3. กดยืนยันจ่ายเงิน ระบบจะตัดสต็อก ออกใบกำกับภาษี และเปิดประกันให้ในคลิกเดียว

ลำดับการทำงาน (เข้าใจง่ายใน 3 สเต็ป)
1.1 ค้นหาเครื่องด้วยเลข IMEI (พิมพ์ค้นหา หรือยิงบาร์โค้ด)
GET /api/v1/products/items/imei/{imei}
กฎก่อนคิดเงิน เช็คให้ชัวร์ว่าเครื่องพร้อมขาย
  • ไม่ต้องมีเครื่องสแกนบาร์โค้ด: หน้าเว็บ Frontend ทำช่อง Input Text ให้พิมพ์เลข IMEI 15 หลักได้ตามปกติ หรือทำ Dropdown เลือกจากรายการสินค้าที่มีในร้านได้เลย
  • ดูฟิลด์ status — ต้องมีค่าเป็น AVAILABLE เท่านั้น (แปลว่าของยังอยู่ในร้าน)
  • หากเป็น SOLD (ขายไปแล้ว) หรือ DAMAGED (เครื่องเสีย) — ห้ามขาย ให้แจ้งเตือนพนักงานบนจอทันที
Request URL 
GET /api/v1/products/items/imei/358912345678901
Response (200 OK) 
{
  "success": true,
  "data": {
    "itemId": 1,
    "modelId": 1,
    "modelName": "iPhone 15 Pro",
    "serialNumber": "SN-IP15P-001",
    "imei": "358912345678901",
    "condition": "NEW",
    "costPrice": 36000.00,
    "sellingPrice": 41900.00,
    "status": "AVAILABLE"
  }
}
1.2 เช็คเบอร์โทรลูกค้า (ดูว่าเป็นลูกค้าเก่าหรือใหม่)
GET /api/v1/customers/phone/{phone}
วิธีผูกลูกค้ากับบิล ค้นหาจากเบอร์โทรศัพท์ก่อนเสมอ
  • ถ้าเป็นลูกค้าเก่า (200 OK): หยิบเอาค่า customerId ไปใส่ในบิลตอนคิดเงินได้เลย
  • ถ้าเป็นลูกค้าใหม่ (404 Not Found): ให้เปิดหน้าจอสมัครสมาชิกใหม่ก่อน แล้วค่อยเอา customerId ใหม่มาคิดเงิน
Request URL 
GET /api/v1/customers/phone/0812345678
Response (200 OK) 
{
  "success": true,
  "data": {
    "customerId": 1,
    "firstName": "สมชาย",
    "lastName": "ใจดี",
    "phone": "0812345678",
    "taxNumber": "1409900123456",
    "address": "123 ถ.มิตรภาพ อ.เมือง จ.ขอนแก่น"
  }
}
1.3 กดยืนยันชำระเงินและออกเอกสาร (จบการขาย)
POST /api/v1/sales
ระบบทำให้ครบในคลิกเดียว พอยิงเส้นนี้ปุ๊บ ระบบหลังบ้านจะจัดการให้ทุกอย่างทันที
  • ไม่มี Hardware สแกนจ่าย / เครื่องรูดบัตร ทำอย่างไร: ทำ Dropdown ในหน้าเว็บให้พนักงานเลือกวิธีจ่ายเงินได้เลย:
    • CASH: รับเงินสด ทอนเงิน แล้วกดยืนยัน
    • TRANSFER: โชว์ QR Code พร้อมเพย์ของร้านบนหน้าจอ ให้ลูกค้าใช้มือถือตัวเองสแกนจ่าย พนักงานตรวจสลิปแล้วใส่เลขสลิปใน referenceNo
    • CREDIT_CARD หรือ INSTALLMENT: รูดบัตร/ผ่อน แล้วใส่เลขอ้างอิงสลิป
  • ตัดสต็อกทันที: สินค้าจะเปลี่ยนสถานะเป็น SOLD ทันที เพื่อไม่ให้ใครเอาไปขายซ้ำ
  • คิดเงินเป๊ะ: คำนวณราคารวม หักส่วนลด และถอดภาษีมูลค่าเพิ่ม VAT 7% ให้เรียบร้อย
  • ออกเอกสารครบ: สร้างเลขที่ใบเสร็จ (saleCode), ออกใบกำกับภาษี (TaxInvoice) และเริ่มนับประกัน (ProductWarranty) ให้อัตโนมัติ

ขั้นตอนที่ 02

รับเครื่องใหม่เข้าสต็อก (ตอนของมาส่งที่ร้าน)

เวลาได้มือถือล็อตใหม่มาส่ง ให้เลือกรุ่น แล้วยิงบาร์โค้ด IMEI ทีละเครื่องเข้าระบบเพื่อบันทึกเป็นของในคลัง

ลำดับการรับของเข้าคลัง
2.1 บันทึกเครื่องใหม่เข้าสู่สต็อก (พิมพ์กรอกข้อมูล หรือยิงบาร์โค้ด)
POST /api/v1/products/items
กฎเหล็กการรับของ ข้อควรระวังตอนบันทึก
  • ไม่ต้องมีเครื่องยิงบาร์โค้ด: พนักงานสามารถพิมพ์เลข IMEI 15 หลัก และ Serial Number ลงในฟอร์มของหน้าเว็บได้โดยตรง
  • imei ต้องเป็นตัวเลข 15 หลัก และ ห้ามซ้ำกับเครื่องที่มีอยู่แล้วในระบบเด็ดขาด
  • serialNumber ต้องไม่ซ้ำกับในระบบ
  • สินค้าที่บันทึกสำเร็จจะกลายเป็นของพร้อมขายทันที สถานะคือ AVAILABLE
Request Body (JSON) 
{
  "modelId": 1,
  "imei": "358912345678901",
  "serialNumber": "SN-IP15P-001",
  "condition": "NEW",
  "costPrice": 36000.00,
  "sellingPrice": 41900.00,
  "grade": "A+",
  "batteryHealth": 100
}
Response (201 Created) 
{
  "success": true,
  "message": "Product item added to inventory successfully",
  "data": {
    "itemId": 1,
    "modelId": 1,
    "modelName": "iPhone 15 Pro",
    "serialNumber": "SN-IP15P-001",
    "imei": "358912345678901",
    "condition": "NEW",
    "costPrice": 36000.00,
    "sellingPrice": 41900.00,
    "status": "AVAILABLE"
  }
}
ขั้นตอนที่ 03

ดูสต็อกของในร้าน & แจ้งเปลี่ยนสถานะเครื่อง

ใช้สำหรับเช็คว่าในร้านเหลือเครื่องอะไรบ้าง หรือถ้าเครื่องทำหล่น จอแตก เสีย ให้มากดเปลี่ยนสถานะที่นี่

แผนภาพสถานะของเครื่องในร้าน (Item Status)
3.1 ปรับสถานะเครื่อง (เช่น แจ้งเครื่องเสีย / ติดจอง)
PATCH /api/v1/products/items/{id}/status
ความหมายของสถานะ เปลี่ยนเป็นอะไรได้บ้าง
  • สถานะที่อนุญาตให้เปลี่ยน: AVAILABLE (พร้อมขาย), RESERVED (มีลูกค้าจองไว้), DAMAGED (เครื่องชำรุด/ส่งซ่อม)
  • สถานะ SOLD (ขายแล้ว) ห้ามมากดเปลี่ยนตรงนี้ ให้ไปทำผ่านหน้าขายของหน้าร้านเท่านั้น
Request Body 
// ค่าสถานะที่ส่งได้: AVAILABLE, RESERVED, DAMAGED, CLAIMING
{
  "status": "DAMAGED"
}
Response (200 OK) 
{
  "success": true,
  "message": "Item status updated successfully",
  "data": {
    "itemId": 1,
    "status": "DAMAGED"
  }
}
ขั้นตอนที่ 04

สมัครสมาชิกลูกค้าใหม่

บันทึกชื่อ เบอร์โทร และที่อยู่ของลูกค้า เพื่อเอาไว้ออกใบกำกับภาษีและเก็บประวัติการซื้อ

4.1 ลงทะเบียนข้อมูลลูกค้าใหม่
POST /api/v1/customers
ข้อมูลลูกค้า ข้อมูลที่จำเป็นต้องกรอก
  • phone ต้องเป็นเบอร์โทรศัพท์ 10 หลัก และใช้เป็นคีย์หลักในการค้นหาหน้าร้าน
  • taxNumber และ address จำเป็นเมื่อลูกค้าต้องการเอกสารใบกำกับภาษีเต็มรูป
Request Body

  "firstName": "สมชาย",

  "phone": "0812345678",
  "taxNumber": "1409900123456",
  "idCard": "1409900123456",

}
Response (201 Created) 
{
  "success": true,
  "message": "Customer created successfully",
  "data": {
    "customerId": 1,

    "lastName": "ใจดี",

ข้อตกลง API

หน้าตาข้อมูลที่ API ส่งกลับมา (ใช้เหมือนกันทุกเส้น)

ไม่ว่าจะยิงเส้นไหน ถ้าทำงานสำเร็จข้อมูลจริงจะอยู่ใน data เสมอ และถ้ากรอกอะไรผิด ระบบจะบอกชัดเจนใน validationErrors

เมื่อสำเร็จ (Success Envelope) 
{
  "success": true,
  "message": "Operation successful",
  "data": { ... },
  "timestamp": "2026-09-15T11:20:00"
}
เมื่อข้อมูลไม่ถูกต้อง (400 Bad Request) 
{
  "status": 400,
  "error": "Bad Request",
  "message": "Validation failed",
  "validationErrors": {
    "phone": "เบอร์โทรศัพท์จำเป็นต้องระบุ",
    "costPrice": "ราคาต้นทุนต้องมากกว่า 0"
  },
  "timestamp": "2026-09-15T11:20:00"
}
สูตรคำนวณ

สูตรคิดเงิน ภาษี และวันรับประกัน

อธิบายวิธีที่ระบบหลังบ้านคำนวณตัวเลขให้อัตโนมัติ เพื่อให้หน้าบ้านแสดงผลได้ตรงกัน

1. วิธีคิดภาษี VAT 7% (รวมอยู่ในราคาสินค้าแล้ว):

- ราคาไม่รวมภาษี = ยอดรวมสุทธิ × 100 / 107
- ภาษีมูลค่าเพิ่ม (VAT 7%) = ยอดรวมสุทธิ - ราคาไม่รวมภาษี
* ตัวอย่าง: ขาย 40,900 บาท → ราคาไม่รวมภาษี = 38,224.30 บาท, ภาษี VAT 7% = 2,675.70 บาท
2. วิธีนับวันรับประกันสินค้า:

- วันหมดประกัน = วันที่ลูกค้าซื้อ (saleDate) + จำนวนเดือนประกันของรุ่นนั้นๆ (เช่น 12 เดือน)
* ใบรับประกันจะถูกสร้างให้อัตโนมัติเมื่อกดยืนยันขายสำเร็จ
